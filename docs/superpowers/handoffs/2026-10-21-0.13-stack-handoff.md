## Lessons

- **A reviewer agent gets an independent clone at the reviewed commit, never
  the live checkout or a branch name.** Two "read-only" reviewers ran
  `git checkout` (one also ran `git pull --rebase`) in the live checkout this
  session. One of them did it mid-way through an npm build, which had to be
  thrown away and rerun. A worktree is not enough, because it shares `.git`.
  After an agent finishes, check `git reflog` before trusting the tree.
- A failing test is a reason to fix the code; whose change caused it does not
  matter.
- `cargo nextest -E 'test(/md_/)'` matches test names only. To run every
  Markdown test, add `binary(/^md_/)`.

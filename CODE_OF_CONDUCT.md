# Code of Conduct

This project follows the
[Contributor Covenant, version 2.1](https://www.contributor-covenant.org/version/2/1/code_of_conduct/).
It applies in the issue tracker, pull requests, discussions and every other
space the project manages, and to anyone representing the project in public.

In short: be respectful, assume good faith, keep criticism about the work,
and do not harass anyone. The Covenant's text is the full statement.

## Reporting

Report behaviour that breaks the Covenant to the maintainers at
`arthur@jandira.tech`. Reports are read by the maintainers only and are kept
confidential. A maintainer who is the subject of a report takes no part in
handling it.

The maintainers answer every report, and decide the response using the
enforcement guidelines of the Covenant: a correction, a warning, a temporary
ban or a permanent ban.

Security problems are not conduct reports: see [SECURITY.md](SECURITY.md).

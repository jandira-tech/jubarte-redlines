# Consulting Agreement — Summary

Prepared for Northwind Traders Ltd. by Jandira Technologies, LLC.
This letter summarizes the engagement agreed on 12 January 2026.

Jandira will redesign the invoicing workflow and deliver documentation
and training for the accounts team.

- Audit the current invoice flow and tooling
- Implement the new template set in the accounting system
- Train the accounts team and hand over runbooks

end the engagement with two weeks' written notice.

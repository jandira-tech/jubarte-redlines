# tests/m_cell_final_marks_pairs.rs: the pairs whose Accept All (or Reject
# All) matches B (or A) block for block but not in its content controls,
# one outcome a line: `from to mode which outcome`. Every outcome that
# appears or goes must change this list.
#
# - control-dropped, Accept: the control B adds is not in the redline.
#   Word's Compare drops it too (Word 16 oracle on #1680, 2026-10-23); #1688.
# - control-dropped, Reject: the control A had is gone. Word keeps it; #1688.
# - control-kept, Accept: the control A had stays where B has none, as
#   Word's Compare keeps it; #1688.
# - control-kept: Accept All or Reject All keeps a block control, emptied,
#   where the other version has none: the redline holds the control, and
#   resolving it takes its words but not the control, as Word's Accept All
#   and Reject All do (#1694).
# - inline-husk: Accept All or Reject All leaves a control inline in a
#   paragraph, emptied or holding the words it kept. Most come from a
#   cell's final mark paired across the control, as Word pairs it (#1680):
#   resolving that mark joins the control's paragraph to its neighbour, and
#   where both bring something to the join, Word makes the control inline
#   too (#1694).
#
# Word 16 resolved the redline of every pair listed here, both ways (the
# #1694 A/B, rounds 6 and 7): jubarte's Accept All and Reject All match
# Word's on all 1,616 resolutions, Word's placeholder run in an emptied
# control included (#1703).

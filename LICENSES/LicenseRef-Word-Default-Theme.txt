Word's default theme (crates/jubarte-opc/src/word_default_theme.rs)

The constant WORD_DEFAULT_THEME in that file holds the theme part
(word/theme/theme1.xml) that Microsoft Word 16 writes into a document that
has none: the Office theme with the Aptos fonts. It is Word's own output,
byte for byte (md5 a3701e91909cce5594ef0a82bdd5c96f), taken from redlines
Word produced.

The theme is Microsoft's, not Jandira Technologies, LLC's, and is not
covered by this repository's Apache-2.0 license. It is reproduced so a
redline whose original has no theme carries the theme Word gives it. The
Rust code around the constant is Jandira Technologies, LLC's, under
Apache-2.0.

# jubarte-doc

The document operations of the [jubarte
engine](https://github.com/jandira-tech/jubarte-redlines) above compare:
changes, comments, validation and repair, audit, scrub, append, field
updates and the maintainer debug/inspect views.

The `render` feature (off by default) adds the operations that need
layout: audit's `word_layout`, the fields update API and the debug
render check.

# jubarte-opc

The package floor of the [jubarte redline
engine](https://github.com/jandira-tech/jubarte-redlines): the OPC
adapter (`opc::PartFs`), input admission with its budgets and refusal
reasons (`admission`), markup simplification and strict-to-transitional
normalization, settings application, and the shared Word tables the
higher layers read (default theme, built-in styles, borders, data
stores, numbering, table DOM questions, Word-validity predicates, and
the pure render option types).

It sits on [jubarte-dom](../jubarte-dom) and owns no document
semantics above the package.

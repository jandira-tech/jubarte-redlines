# jubarte-edit

The edit product of the [jubarte
engine](https://github.com/jandira-tech/jubarte-redlines): edit plans
in, tracked changes out - rewrite, insert, tables, lists, run
formatting, footnotes, images, page setup, content controls, watermark,
redact, settings and field updates. `text_diff` renders text diffs as
the agent view prints them, `expect` checks plans against their schema
(v2 schema bundled under `schemas/`), `capabilities` names what the
bindings expose, and `publication` stages host filesystem output.

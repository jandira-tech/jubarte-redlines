# jubarte-cli

The [jubarte engine](https://github.com/jandira-tech/jubarte-redlines)'s
command line: every operation of the library behind one clap surface -
compare, convert, changes, accept, reject, edit, read, validate, audit,
scrub, append, comments, fields, debug - plus `self-update` behind its
feature. `--version` carries the source commit when built from this
repository.

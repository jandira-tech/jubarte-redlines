### csf_9e40f23e742aa43493a0fb92 — Rendering a small DOCX table can exhaust host memory
- Severity: medium
- Summary: An untrusted DOCX author can set huge positive w:gridSpan, w:gridBefore or w:gridAfter counts in a small, shallow table. Rendering sums those counts into grid occupancy and directly sizes column, preference and merge vectors. Counts of 1000000000/1073741824 request about 4 GB/4 GiB for f32 columns; 4294967295 requests approximately 16 GiB before additional allocations, despite package admission. Assigned discovery-0031 corroborates the existing one-billion-column, 4,000,000,000-byte f32-vector framing through both span and row-skip inputs; these are static counts.
 Assigned discovery-0032 corroborates the live span and both synthetic row-skip paths, including merge-slot expansion; separate Markdown span clamping does not protect rendering.
- Remediation: Enforce practical per-span and total-column budgets for gridSpan, gridBefore and gridAfter before excessive RawCell, column, preference or merge allocation/work. Use checked occupancy sums and col+span arithmetic, apply the same budget to every derived table vector, and return a typed resource-limit refusal on excess. Propagate a caller-adjustable semantic column limit through all public rendering surfaces and charge later column/merge vectors to that same budget.
Additional retained remediation detail: Enforce explicit maximum live cell spans, row skips, aggregate table columns and merge slots before any allocation. Use checked sums and a cumulative layout resource budget, returning a typed refusal when exceeded.

### csf_ad0603057507f1d6be6e9942 — Shallow malformed XML can bypass admission and overflow the DOM parser stack
- Severity: medium
- Summary: Malformed unquoted attributes can make tolerant package admission observe shallow XML while the permissive DOM constructs deeply nested elements without a depth guard. Repeated sibling <p a=//> tags are one framing; a=x followed by b="x>..." can expose attribute-contained <n> tags as another. Rendering is the earlier affected route; WmlDocument::from_bytes followed by lazy main_document is the newly supplied route. Strict checked inspection rejects the malformed attribute form. A further supplied shallow sibling framing, <a b=x></a>x>, makes the DOM swallow the closing tag as attribute text and treat following siblings as descendants.
- Remediation: Make tolerant attribute tokenization identical between admission and DOM construction or refuse unsupported unquoted values, and enforce a real construction-depth limit or use an iterative DOM parser.

### csf_0e2b085a251b34412cd71a4c — Reading or converting nested legacy DOC fields can monopolize the processing thread

Keep legacy diagnostic probes cheap and bounded, or enforce the same field/work budgets before invoking the full reader solely for a refusal hint.

### csf_3201e6caaef21850d61fa69c — WMF record-boundary failures amplify polygon work and retained text

About 1 MiB can request multiple gigabytes of retained text; valid whole-file reads, nonblank text and nonzero mapping extents remain required. No out-of-bounds memory read is asserted.

Before allocation validate fixed fields, ring/point counts and coordinate arrays, EXTTEXTOUT options/optional rectangle and text count, and TEXTOUT padded string plus trailing coordinates against that slice using checked arithmetic. Refuse inconsistent records before decoding/rasterization/replay and enforce cumulative decoded-text, record and total geometry/work budgets. Keep the already bounded EMF behavior.

# Threat Model

Jubarte is an in-process Word document engine exposing Rust byte APIs, a native CLI, PyO3/Python APIs and CLI, wasm-bindgen byte APIs and a Node CLI. It reads DOCX/OOXML, Markdown and supported legacy DOC inputs; compares, inspects, edits, resolves revisions, validates/repairs, scrubs and renders documents. Explicitly authorized host adapters publish resulting documents, reports, PDFs and PNGs. A Python MCP adapter serves document tools over stdio under a caller-selected directory capability. Native self-update and maintainer release publication are separate privileged workflows. The independent architecture reviewer reported current HEAD 41019ae16a6123f0273af0ca997901c85437be12; the scan-directory basename was not treated as its revision. Evidence: README.md:12-16,29-42; src/lib.rs:15-35,163-165; jubarte-python/pyproject.toml:42-49; jubarte-python/python/jubarte_redlines/mcp_server.py:373-381; src/update.rs:186-210.

## Assets

- Confidential document bytes and extracted text, including paragraphs, comments, revisions, metadata, embedded images/fonts and relationship targets; generated clean/redline DOCX, rendered PDF/PNG and edit/audit reports. MCP intentionally returns text through read tools and page text through rendering, while document/image bytes are published as files. Evidence: jubarte-python/python/jubarte_redlines/mcp_server.py:132-150,185-217,229-255; docs/adoption/mcp.md:69-73.
- Integrity of edited documents, source snapshots and revision attribution. SHA-256 protects optional edit-plan snapshot binding; paragraph/text anchors and plan preparation protect edit applicability. Author strings are supplied document metadata, not authenticated identities. Evidence: src/inspect.rs:273-277; src/edit.rs:1744-1761,2073-2105; jubarte-python/python/jubarte_redlines/mcp_server.py:258-276.
- Filesystem authority granted to the MCP server: explicit input reads and output publication beneath resolved --root, defaulting to startup working directory. The persistent native OutputRoot holds a cap-std directory handle. This is distinct from ambient filesystem authority used by CLI adapters and renderer font/cache operations. Evidence: jubarte-python/python/jubarte_redlines/mcp_server.py:67-108,373-381; jubarte-python/src/lib.rs:1244-1277; src/publication.rs:146-199,203-225.
- Renderer resources outside explicit document paths: installed font files, Word cloud fonts and a persistent font-index TSV containing font source paths, file stamps and directory stamps. Default index location is the parent of Jubarte's font directory plus font-index.tsv, not a child of fonts/. Evidence: src/convert/font.rs:2258-2315,2633-2652,3090-3106,3154-3169,3192-3227.
- Process memory, CPU and availability across native, Python and WASM callers. Default package admission allows 64 MiB compressed and per part, 256 MiB inflated, 10,000 entries and XML depth 256; comparison uses 512 MiB compressed/per part and 2 GiB inflated with the same entry/depth limits. XML limits default to 1,024 attributes, 1,024-byte attribute names, 64 MiB values and 128 MiB start tags. These are configured objectives, with actual enforcement findings recorded separately. Evidence: src/admission.rs:63-100; src/xmllinq/parse.rs:49-57.
- Installed native executable and the trusted release channel; release archives, SHA256SUMS.txt, optional signing-key material, GitHub release write authority and registry publication authority. Current updater trust configuration has no release public keys and no first-signed-release version. Evidence: src/update.rs:25-48,198-210,245-257; .github/workflows/release.yml:235-275,278-308,356-369; scripts/release.sh:72-84,105,375-380.

## Trust Boundaries

- Untrusted document producer -> host process -> package admission and parsers. The host supplies bytes; admission implements archive size/count/inflation and structure controls before consumers parse input, including the shared ZIP structural pass. No disk extraction or external relationship fetching is part of admission. Public parse_xdocument deliberately does not enforce input policy; checked variants validate before DOM construction. Enforcement defects found in this audit remain separate from these intended controls. Evidence: src/admission.rs:13-28,397-407,439-470; src/opc/archive.rs:15-51; src/xmllinq/parse.rs:85-135.
- Document/edit-plan producer -> edit transaction -> transformed package bytes. Plans have schema checks, optional source_sha256 verification, exact-anchor failure modes and signed/macro-bearing source refusal; apply_plan returns prepared results rather than publishing files. Snapshot hashing authenticates neither author nor caller. Evidence: src/edit.rs:1740-1761,2073-2105; src/inspect.rs:273-277.
- MCP client/model -> stdio server -> explicit root-relative input reads. Startup resolves --root or current working directory, opens one native OutputRoot and passes lexical relative names to read. Python resolution is an early diagnostic; actual confinement belongs to held cap-std directory capability. Tools do not establish independent users/tenants. Gemini extension starts uvx --from jubarte-redlines[mcp] jubarte-mcp --root ${workspacePath}, giving the same capability rooted at the host-selected workspace. Evidence: jubarte-python/python/jubarte_redlines/mcp_server.py:67-89,373-381; jubarte-python/src/lib.rs:1244-1262; src/publication.rs:146-165; gemini-extension.json:5-8.
- MCP client/model -> brokered publication under the same held root. docx_edit derives out_dir/clean.docx, redline.docx, patch.diff and report.json, optionally redline.pdf and redline-page-NN.png; docx_render derives out_dir/page-NN.png and render.pdf; compare/accept/reject use caller-selected output names. OutputRoot validates portable relative names, capability directories and output symlinks, stages/verifies files, and atomically installs each without clobber unless overwrite=true. Atomicity is per file; errors report committed files. Evidence: jubarte-python/python/jubarte_redlines/mcp_server.py:101-112,185-217,229-277,285-298; src/publication.rs:83-143,168-199,228-273,431-482,535-570.
- MCP registration/annotations -> external host approval policy. read_only_hint and destructive_hint are hints, not server-side caller authentication or approval enforcement. Host chooses approval policy; admitted calls can request overwrite=true and share a root. Evidence: jubarte-python/python/jubarte_redlines/mcp_server.py:54-55,152-160,220-228; docs/adoption/mcp.md:39-41,168-169.
- Native CLI operator -> ambient local output paths. publish_paths holds selected parent directory handles and stages verified bytes under sibling .jubarte-<UUID>.partial/bytes with private Unix permissions; typed edit publication rechecks input hash and output aliases/collisions. Partial commits may remain after a later error. This grants ambient access rather than MCP root confinement. Evidence: src/publication.rs:203-225,431-505,535-570; src/bin/jubarte.rs:261-273,1642-1656,1764-1812.
- Python/Node CLI operator -> ambient filesystem. Python _write uses Path.write_bytes and Node write uses fs.writeFileSync after adapter path/force checks; these do not inherit native publication merely from shared engine grammar. Python Document.read uses ambient read_bytes; in-memory operations return bytes. Evidence: jubarte-python/python/jubarte_redlines/document.py:117-145; jubarte-python/python/jubarte_redlines/__main__.py:116-133; jubarte-wasm/cli/bin/jubarte-redlines.mjs:52-79,106-111.
- Document-selected font family -> native renderer -> ambient font stores using std::fs, outside MCP OutputRoot. Own-font directory precedence: nonempty JUBARTE_FONT_DIR, otherwise macOS HOME/Library/Application Support/jubarte/fonts; other Unix XDG_DATA_HOME/jubarte/fonts or HOME/.local/share/jubarte/fonts (HOME required); Windows APPDATA/jubarte/fonts. System/Word discovery separately uses /System/Library/Fonts/Supplemental, /Library/Fonts, /Applications/Microsoft Word.app/Contents/Resources/DFonts, /Library/Fonts/Microsoft, /System/Library/Fonts and HOME/Library/Group Containers/UBF8T346G9.Office/FontCache/4/CloudFonts/<family>. Cloud family is one normal path component. Windows discovery uses WINDIR, else SystemRoot, else C:\Windows joined with Fonts, plus LOCALAPPDATA/Microsoft/Windows/Fonts. These resources feed font parser/shaper and rendered output, controlled by ambient OS permissions. Evidence: src/convert/font.rs:2230-2235,2258-2315,2324-2376,2460-2467,2633-2652,2814-2862.
- Native renderer -> persistent ambient font-index state. JUBARTE_FONT_INDEX empty/off disables; another value is complete path; absent value derives parent(user_font_dir())/font-index.tsv. Effective defaults: HOME/Library/Application Support/jubarte/font-index.tsv on macOS, XDG_DATA_HOME/jubarte/font-index.tsv or HOME/.local/share/jubarte/font-index.tsv on other Unix, APPDATA/jubarte/font-index.tsv on Windows. JUBARTE_FONT_DIR overrides instead derive its parent/font-index.tsv. Reads reuse stamped source paths; writes create parent, write sibling font-index.tsv.<pid>.tmp then rename. No MCP-root control applies; OS permissions, index version/header, file/directory stamps are effective controls. Evidence: src/convert/font.rs:2637-2652,3095-3112,3154-3188,3213-3229.
- JS caller -> WASM linear memory -> shared engine. WASM exports take byte arrays/JSON and return bytes/results, omit self-update, and cfg-exclude native publication. Node CLI separately supplies filesystem authority. WASM compare inherits roomier 2 GiB inflated comparison budget and documentation tells browser hosts to lower it. Evidence: jubarte-wasm/Cargo.toml:18-32; jubarte-wasm/src/lib.rs:63-97; src/lib.rs:163-165; jubarte-wasm/cli/bin/jubarte-redlines.mjs:16-21,52-55,106-111.
- Operator -> explicit native self-update -> GitHub release/archive/SHA256SUMS.txt -> executable swap. Fixed jandira-tech/jubarte-redlines and OS/arch target select archive and member jubarte-<version>-<target>/jubarte (Windows jubarte.exe). macOS/Linux use tar.gz, Windows ZIP; extraction/swap delegated to self_update. Noninteractive requires --check or --yes before network lookup; interactive installation confirms. verify_binary rejects nonregular extracted binary. RELEASE_KEYS=[] and FIRST_SIGNED_RELEASE=None mean checksum-only verification, matching staged-signing docs. Evidence: src/update.rs:25-48,91-108,120-125,186-210,212-257; Cargo.toml:137-148; docs/SELF_UPDATE.md:22-45,57-87.
- Maintainer/tag authority -> GitHub Actions builds -> release publication. v* tag triggers tag/version check and per-platform locked read-only builds; release job gets contents:write and same-run artifacts. Optional signing alone receives ZIPSIGN_PRIVATE_KEY, decodes to RUNNER_TEMP/zipsign.<random>/keyN, signs dist archives, verifies committed keys/*.pub and deletes keys on exit. Checksums follow signing. GITHUB_TOKEN maps to GH_TOKEN for gh release create at GITHUB_REF_NAME in github.repository, notes.md and dist/*. Local release.sh additionally publishes registries and runs security-check.sh even when ordinary gates skipped. Evidence: .github/workflows/release.yml:15-25,40-49,51-89,235-308,317-322,356-369; scripts/release.sh:72-84,105,375-380,654-678.
- Developer benchmark worker -> ambient paths over stdin COMPARE basePath nextPath outPath -> std::fs reads/writes. It is a same-user speed harness, not a hosted network service; independently exposed deployment would require separate controls. Evidence: jubarte-rust-inproc/src/main.rs:5-20,29-69,91-99.

## Attacker Capabilities

- A document producer controls container records, XML/relationships, text, revision/comment metadata, embedded media/fonts and legacy DOC bytes. This is a parser/resource boundary without proof of a public service. Input budgets/shared ZIP checks/checked XML are existing controls, not proof of complete DoS resistance. Evidence: SECURITY.md:33-80; src/admission.rs:13-28,63-100,439-470.
- An MCP client/model chooses exposed tool arguments, relative paths, plans, output names and overwrite flags within root. It does not thereby control --root, environment/font-index settings, installed binary, signing keys or release credentials. All calls share root; no tenant identities established. Evidence: jubarte-python/python/jubarte_redlines/mcp_server.py:67-108,152-160,220-228,373-381.
- Untrusted returned text may influence a consuming model, but interpreting it as instructions/granting tools is an external host decision. MCP hints are metadata, not identity enforcement. Evidence: jubarte-python/python/jubarte_redlines/mcp_server.py:54-55,132-150; docs/adoption/mcp.md:39-41.
- Replacing release assets plus adjacent checksum differs from source/build/signing-key authority. Present updater does not have independent signature trust root. GitHub publication/transport compromise is an additional prerequisite, not granted by ordinary document input. Evidence: src/update.rs:44-48,198-210,245-257; docs/SELF_UPDATE.md:59-80.
- Write access to shared output/font/cache state could influence a privileged consumer but must be established for a deployment. Publication mitigates races with held directories/staging/atomic installation; renderer cache has separate ambient authority. Evidence: src/publication.rs:431-482,535-570; src/convert/font.rs:3154-3188,3213-3229.

## Security Objectives

- Refuse malformed/ambiguous/over-budget documents before unrestricted package inflation/DOM work; preserve checked versus raw XML distinction. Use host CPU/memory limits rather than claiming comprehensive execution limits from admission. Findings record exceptions. Evidence: src/admission.rs:39-40,63-100,397-407,439-470; src/xmllinq/parse.rs:90-135; SECURITY.md:74-80.
- Confine explicit MCP document I/O to startup root, preserve no-clobber unless overwrite=true, report partial commits/durability uncertainty. Do not mistake broker controls for process-wide sandboxing. Evidence: src/publication.rs:36-46,146-199,431-482,535-570; jubarte-python/python/jubarte_redlines/mcp_server.py:67-108.
- Bind edit plans to inspected bytes when source_sha256 supplied; refuse unsupported schema/stale snapshot/ambiguous anchors before publication. Author attribution is separate from authentication. Evidence: src/edit.rs:1744-1761,2073-2105; src/bin/jubarte.rs:1642-1656,1781-1805.
- Protect confidential document and derived output across returned text/artifacts/reports. Scrub/redaction are explicit transformations requiring dedicated review; successful conversion/validation does not establish confidentiality. Evidence: src/lib.rs:19-27; jubarte-python/python/jubarte_redlines/mcp_server.py:132-150,185-217,245-255.
- Restrict executable replacement to deliberate updater, intended repository/platform/release and configured checksum/signature/regular-file policy. Keep checksum-only state explicit until keys compiled in. Evidence: src/update.rs:25-48,91-108,120-125,198-210,240-257.
- Scope release credentials to consumers and bind artifacts to version/tag/build outputs. Signing keys, GitHub release credentials and registry tokens are distinct capabilities. Evidence: .github/workflows/release.yml:40-49,89,235-308,317-322,356-369; scripts/release.sh:72-84,105,375-380.
